## 🚀 Featured work

### 🎟️ QR Code Event Check-in System
A complete registration and check-in system for a company event expected to host around **30,000 participants**.
- Website and database built to handle registrations at that scale
- Authentication for staff, so only authorized employees can scan QR codes at the entrance
- WhatsApp message templates that remind participants, let them confirm or cancel, and explain what they will gain from attending
- Follow-up emails after confirmation, all kept in a single email thread

### 💬 AI Customer Assistant (Telegram)
An AI agent powered by Gemini that answers customers' text and voice messages, saves bookings, logs every conversation, and hands complex cases to a human team.

### 📱 WhatsApp AI Agents
AI agents connected through the WhatsApp Business Cloud API and third-party providers, with custom system prompts and a Supabase database for storing and retrieving customer data in real time.

### 📧 AI Email Processing Pipeline
Reads incoming emails, translates and summarizes them with Groq, logs them to Google Sheets, turns them into PDF reports through a self-hosted Gotenberg service in Docker, and sends them on Telegram.
